If a message looks suspicious, report it - a false alarm costs us nothing, a missed
phishing mail costs a lot.

## Reporting a suspicious e-mail

Use the **Report phishing** button in Outlook. It forwards the message with its full
headers to the security team and removes it from your inbox. Do not forward suspicious
mail manually: forwarding strips the headers we need.

## If you already clicked

1. Disconnect from the network (turn off Wi-Fi, unplug the cable).
2. Call the security hotline on extension 4599. It is staffed 24/7.
3. Do not shut the laptop down - volatile memory is useful for the analysis.
4. Change your password from a different device - see kb-001.

## What counts as an incident

A lost or stolen device, a suspected malware infection, data sent to the wrong recipient,
an unknown person following you through a badge-controlled door, or a credential you
believe has been exposed. When in doubt, report it.

Response targets: acknowledgement within 15 minutes, first assessment within one hour.
